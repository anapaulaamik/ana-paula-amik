# Página pessoal · Ana Paula Amik

Página estática pronta para publicar na Vercel usando o GitHub, sem terminal.

## Publicar pelo GitHub e pela Vercel

1. Extraia o arquivo ZIP.
2. No GitHub, crie um repositório para a página.
3. Envie para o repositório os arquivos e pastas que estão dentro de `amik-bio-link`, mantendo `index.html` na raiz e a pasta `assets` no mesmo nível.
4. Na Vercel, escolha **New Project**, conecte o GitHub e importe esse repositório.
5. Deixe a detecção automática para uma página estática e escolha **Deploy**.
6. A Vercel vai gerar um endereço para abrir e revisar a página.

Depois, cada atualização enviada ao repositório pode gerar um novo deploy pela integração com GitHub.
